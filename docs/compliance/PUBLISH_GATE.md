# 内容发布版权门槛

## 当前机制

- 新建文章会自动生成版权资产记录，初始状态为 pending / unknown。
- 新建教育资源默认私有。若请求直接公开，服务端返回 409；需要先保存私有版本。
- 文章发布、私有教育资源转公开、恢复回收站中的公开内容，必须匹配当前版本的 SHA-256 资产记录。
- 通过条件：审核状态为 approved 或 approved_with_conditions；授权状态为 confirmed 或 conditional；已明确权利依据；并存在已核验的对应证据。
- original/commissioned 需要作者声明、合同或法律审核证据；licensed/third_party_permission 需要许可证文本、授权邮件、合同、购买凭证或法律审核证据；open_license 还必须关联已经人工审核且标记允许商业用途的许可证目录记录；public_domain 需要来源或法律审核证据。
- 内容/资源版本变化会生成或重置相应审核记录。发布门槛使用当前版本哈希，不允许借用旧版本的审核结果。
- 已公开内容不会因为首次扫描而自动删除或下架。已发布文章需先取消发布再修改；已公开资源需先取消公开再修改。审核通过后才能再次公开。
- 软删除/回收站会将资产标记为非活动状态；恢复公开内容时仍需验证当前版本的权利审核。

## 证据边界

该门槛是风险控制，不是法律裁决。来源 URL、作者署名、文件存在许可证文本或自动扫描均不等于获得授权。管理员必须实际核对证据内容、商业使用范围、署名/保留声明、修改/再分发限制和适用条件，再将证据标记为已核验。

## 当前例外与待处理事项

- 扫描前已公开的内容仍保持现有公开状态，直到所有者决定下架、替换或补充授权。
- 目前尚未自动将任何账户提升为版权合规管理员；须先核实账户身份再授予管理员权限。
- 版权投诉表单仅在“版权投诉”与“隐私政策”均正式发布后启用。
