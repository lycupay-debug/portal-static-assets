# 中国商业网站信息与数据合规研究底稿

> 研究日期：2026-10-17。此文件是项目技术合规研究底稿，不是律师出具的法律意见，也不代表网站已满足全部义务。应以主管机关公布的正式文本、网站实际运营主体、服务器位置、服务内容和数据流为准。

## 1. 需核验的法规与运营事实

| 领域 | 参考来源 | 需要核验的事项 |
|---|---|---|
| 个人信息保护 | 《中华人民共和国个人信息保护法》及主管机关正式文本 | 处理者身份与联系方式、处理目的/方式、信息种类、保存期限、用户权利渠道、委托处理和跨境数据流。 |
| 隐私与人格权益 | 《中华人民共和国民法典》人格权编 | 账号资料、姓名、肖像、声音及其他个人信息的收集、展示、访问和删除机制。 |
| 互联网信息服务 | 《互联网信息服务管理办法》及主管机关正式文本 | 网站主办者、业务是否有偿、备案/许可状态、首页展示要求及是否涉及专项服务。 |
| 网络信息内容治理 | 《网络信息内容生态治理规定》及主管机关正式文本 | 网站角色是否适用、用户协议、公开管理规则、一般内容治理和举报处理流程。 |
| 网络安全 | 《中华人民共和国网络安全法》及现行修订文本 | 账号安全、服务器和数据安全、访问控制、日志及事件处置机制。 |

具体义务须结合运营主体、服务模式、数据处理事实、服务器托管地和适用条款确认。本研究不替代法律意见、备案核验或专项合规评估。

## 2. 技术盘点中确认的事实

- 账户注册字段包含邮箱、显示名称和密码；服务端使用密码哈希存储验证值，登录使用安全 Cookie 和会话令牌哈希。
- 网站包含公开内容、互动、教育资源上传/下载等功能。
- 当前域名使用 Cloudflare 代理/CDN/安全服务；访问日志字段、处理地点、保存期限、数据处理协议和跨境路径仍需依据实际配置核验。
- 隐私政策和使用条款保持草稿；在事实信息、处理期限和联系渠道核实前，不应将其标记为已生效。

## 3. 政策发布前需要补齐的事实

1. 运营主体法定全称/经营者姓名、联系地址及稳定联系渠道。
2. 网站备案/许可状态、适用的备案或许可证编号及首页展示要求。
3. 实际主机/备份地区、第三方服务的数据处理关系、实际日志字段与保存期限。
4. 账户、内容、互动和上传文件的保存期限、删除规则及用户权利请求渠道。
5. 若服务面向未成年人或收集不满十四周岁未成年人的个人信息，专项确认适用要求。

## 4. 技术与治理原则

- 不在政策中填写未经核实的运营主体、服务商、保存期限或数据地点。
- 权限控制在服务端执行；敏感管理功能不因前端隐藏按钮而视为受保护。
- 日志和扫描报告限制访问权限；保留必要审计，但避免在日志中写入不必要的个人信息。
- 政策先保持 `draft` 或 `in_review`；只有事实信息补齐、占位符移除并完成相应审核后才允许发布。
- 网站备案、增值电信业务许可及教育等专项许可，应按运营主体、托管位置、服务模式和业务内容另行核验。

## 5. 审核边界

本报告是基于可访问代码、数据库结构和公开法规来源的技术研究。它不能替代主管机关要求的专项评估、合同审查或专业法律意见。
